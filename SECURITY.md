# Security policy

Bible Family Feud is a static website. It has no accounts, no database and collects no personal data. The only thing it stores is the team names and round count you choose, saved in your own browser.

## Reporting a vulnerability

Please report security issues privately rather than in a public issue:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability** and describe what you found.

If that option is not shown, open a regular issue that says only that you have a security concern, without details, and a maintainer will arrange a private channel.
